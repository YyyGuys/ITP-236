Course Code Examples & Weekly Demonstrations
Welcome to the official code repository for ITP‑236 (C# II). This space contains all in‑class examples, weekly demonstrations, and reference projects used throughout the semester. Everything here is read‑only for students — feel free to explore, clone, or download the code as needed.

Repository Structure
The repository is organized by week and topic:
ITP-236/
├── Week01_Review/
├── Week02_OOP/
├── Week03_Inheritance/
├── Week04_Interfaces/
├── Week05_Collections/
└── AdditionalExamples/
Each folder includes:
- A Visual Studio solution or project
- Example code shown in class
- Occasional notes or comments to reinforce key concepts

How to Use This Repository
Option 1 — View Online
You can browse all files directly on GitHub without installing anything.
Option 2 — Download as ZIP
- Click the green Code button
- Select Download ZIP
- Extract the folder
- Open the .sln file in Visual Studio
Option 3 — Clone the Repository (recommended for advanced students)
If you have Git installed:
git clone https://github.com/ITP-236/REPO_NAME_HERE.git

Course Goals Supported by This Repo
This repository reinforces:
- Object‑oriented design
- Inheritance, interfaces, and polymorphism
- Exception handling
- Collections and LINQ
- File I/O
- API fundamentals (if applicable)
Each example is intentionally small, focused, and aligned with weekly learning objectives.

Notes for Students
